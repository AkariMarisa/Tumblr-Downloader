# 测试计划

覆盖 app 所有用户可见的流程，按模块分组。状态标记：

* ✅ **自动化** — 由 JVM 单元测试覆盖（`./gradlew testDebugUnitTest`，212 个）
* 📱 **实机验证** — 在真机上手工执行过（SHG01，Android 14，中文界面）
* ⬜ **待执行** — 已设计，尚未执行
* ❌ **未通过** — 已执行但未达预期（在回归清单中跟踪）

设计原则：预期优先从用户体验出发——明确的提示优于静默，宁可重复下载也不做用户无法理解的静默去重（见 7.10）。

自动化套件：`./gradlew testDebugUnitTest lintDebug assembleDebug`。
实机用例用 `adb` 驱动（`uiautomator dump` 断言 UI，`logcat` 断言行为）。
